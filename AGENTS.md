## Architecture

```
index.mjs         Main entry — Baileys socket, message handler, shared state
server.mjs        Raw http server — /healthz, /qr, /send
autoreply.mjs     Client auto-reply (Claude/Groq/OpenRouter + fallback)
ticket.mjs        Ops ticket creation + ack send
supabase.mjs      Auth state (Baileys), settings, heartbeat, thread updates
clients.json      Client allowlist { phone: "Name — Company" }
```

**`shared` object** (in-memory, read by `/healthz`):
- `linked` — Baileys connection state
- `lastEventAt` — MUST stay fresh for WhatsApp to show "Active" on Linked Devices

## Activity Keepalive (CRITICAL)

WhatsApp shows "Active" only when `lastEventAt` is recent.

**Three mechanisms (all required, commit `faed627`):**
1. `index.mjs` `setInterval` — bumps `shared.lastEventAt` every 5 min while linked
2. `autoreply.mjs` `onSent` callback — bumps immediately after every outbound auto-reply
3. `ticket.mjs` `onSent` callback — bumps immediately after every ticket ack send

**NEVER remove these.** If WhatsApp shows "last active X ago" after a deploy:
1. Check `GET /healthz` → `linked: true`?
2. Check commit `faed627`+ is deployed
3. If `linked: false`, scan QR at `/qr?token=jst-qr-2026`

## Validated Message Templates (NO EMOJI, NO "waiting")

### Template 1 — AI Contextual Reply (primary)
Generated by Claude/Groq/OpenRouter. System prompt enforces:
- Acknowledges specifically what client said
- 1-3 sentences, WA-natural tone
- Never quotes price or makes commitment
- Never mentions AI
- Ends: `— Jordan, J Supreme`

### Template 2 — Fallback (when all AI providers fail)
```
Hi {first}, thanks for reaching out. Jordan has your message and will respond personally. Office hours: {OFFICE_HOURS}.
— Jordan, J Supreme
```
- `OFFICE_HOURS` env var (default: `Mon-Fri, 9am-5pm (Jamaica)`)

### Template 3 — Ticket Acknowledgment
```
Hi {first}, your message has been received and logged (ref: {ticketRef}). We will review and respond shortly. You can reply here if you have additional details.
```

**Rules:**
- NO emoji in any template
- NO "waiting", "please wait", "stand by", "will be in touch" dead-end language
- NO price quotes, commitments, or AI disclosure
- Cooldowns: autoreply = 3 min per chat, ticket ack = 30 min per chat
- Startup grace: no replies for 15 min after bot boot
- Jordan reply suppression: skip autoreply if Jordan replied within 2h

## Common Issues

| Symptom | Cause | Fix |
|---------|-------|-----|
| `/healthz` returns 404 | Wrong codebase deployed (AI sales bot) | Force-push local master, redeploy |
| `linked: false, hasQR: true` | Session expired | Scan QR at `/qr?token=jst-qr-2026` |
| Device shows "last active X ago" | `lastEventAt` stale | Verify `faed627`+ deployed; keepalive running |
| No autoreply to Owen | Number not in allowlist or cooldown active | Check `clients.json` + wait 3 min |
| Emoji in message | BOM corruption from PowerShell Set-Content | Use `[System.IO.File]::WriteAllText` with `[System.Text.Encoding]::UTF8` |
